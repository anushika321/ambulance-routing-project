# Ambulance Routing Project

A web-based ambulance routing project using C, HTML, and a routing engine.

## Files

- `index.html` — Web interface
- `server.c` — Server program
- `engine.c` / `engine.h` — Routing engine
- `Makefile` — Build instructions
- `ambulance.exe` and `engine.exe` — Compiled programs

## How to run

Use the Makefile to build the project, then start the server.
